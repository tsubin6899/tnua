# 國立臺北藝術大學招生互動儀表板

這個資料夾包含可直接發布到 GitHub Pages 的靜態網站，以及可選用的中央共用模式；首頁為 `index.html`。

## 發布方式

1. 將本資料夾的變更提交並推送到 GitHub 的 `main` 分支。
2. 到 GitHub 專案的 **Settings → Pages**。
3. 在 **Build and deployment** 選擇 **Deploy from a branch**。
4. 分支選擇 `main`，資料夾選擇 `/(root)`，再按 **Save**。

## 中央共用模式

若需要多人共用資料、登入權限、草稿／正式發布與版本回復，請依 [中央模式操作說明](中央模式操作說明.md) 啟動 `central-server.mjs`。直接發布到 GitHub Pages 或直接開啟 `index.html` 時，網站仍維持私人本機模式。

## 資料編輯說明

- 篩選順序為「學年度 → 學制 → 資料狀態 → 招生管道 → 學院 → 系所」；資料狀態預設只顯示已完成（正式）資料，可另切換進行中、預估或全部。
- 儀表板拆分為「總覽、決策報告、趨勢、名額調整、名額資料、資料明細」六個分頁，分頁位置會保留在網址中，主要篩選條件由分析分頁共用。
- 「總覽」新增招生轉換漏斗與同年度系所健康矩陣，可快速辨識報名、錄取、註冊報到的流失階段，以及低競爭、低報到或持續缺額系所。
- 「趨勢」新增報名、名額、錄取、註冊報到四項小倍數圖、系所 × 學年度指標熱圖與招生管道構成圖；以所選學年度為截止點，並連動學制、招生管道、學院與系所。
- 「決策報告」新增需求 × 到位四象限與近三年衰退／持續缺額排行，可切換持續缺額、報名變化及報到率變化。
- 熱圖指標、健康矩陣排序、決策排行指標及管道構成模式會保留在網址與目前瀏覽器，方便分享及重新開啟相同分析狀態。
- 學制名稱統一顯示為「學士班」；學院、學士班學系及研究所系所皆依校方指定順序排列。
- 頁首包含北藝大品牌導覽列；各主要標題使用一致的小圖示，並可快速前往總覽、決策報告、趨勢及資料明細。
- 「招生決策統計報告」會依目前篩選即時計算本期、前期及近 3 期平均，並依報名變化、競爭倍率、錄取率、報到率、缺額、備取、錄取不足額與名額回流產生優先行動建議。
- 「精確資料明細」中的報名、名額、錄取、備取人數、錄取不足額、名額回流、註冊報到可直接編輯；表格會完整向下展開，僅保留水平捲動。
- 「精確資料明細」的學院名稱以固定色彩標籤區分，並保留完整文字名稱供辨識。
- 明細表以藍綠底標示「年度總計／全校」最高層級資料，並固定左側資料層級欄，方便橫向閱讀大量欄位。
- 備取人數與錄取不足額依各年度 Excel 的實際欄位擷取；原表沒有欄位時留白。
- 特殊選才、申請入學、繁星推薦及甄試入學會顯示原表的「流回單招／流用一般考試」數值，其他管道不開放此欄。
- 私人本機模式的編輯只保存在目前瀏覽器；中央共用模式則由編輯者儲存共同草稿，再由管理者正式發布給檢視者。
- 未填的錄取或註冊報到數會保留為「待補」，不會轉成 0，也不納入相關比率與缺額計算。
- 可使用「匯出目前 CSV」保存目前篩選與編輯後的資料。
- 可下載本資料夾內的 `國立臺北藝術大學招生自填資料匯入範本.xlsx` 批次維護自填資料。
- 如要回到內建數值，按「還原編輯數值」。

網站已包含瀏覽器分頁圖示、Apple Touch Icon 與 Web App Manifest；加入手機主畫面時會使用北藝大招生 APP 圖示。
